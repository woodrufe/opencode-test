Find Your WSL Files

When working on Windows with a Linux subsystem (WSL), locating your distro's files can be confusing. This page shows you quick ways to find them — either through Windows Explorer or by using well‑known paths.

Finding your Files without Powershell

In Windows File Explorer, you can reach your distro's home folder by following this path:

  • Linux → Ubuntu → home → [Your User Name]

Common paths

Typical locations your distro data lives (replace DistroName with your actual distribution name):

From Explorer (\\wsl$)
\\wsl$\DistroName — shows the default filesystem root of the running distro.
From the user profile folder
%APPDATA%\local\packages\DistroName\local-state\ — home directory files (documents, pictures, etc.).
Distro install directory
%APPDATA%\local\packages\DistroName\ — where the package filesystem is mounted.
From a WSL terminal
From the WSL command line, your distro home is at ~; use your distro's file manager or wslpath to browse files from Windows.
